## Some things I've made

- **[Okkhor](https://ashik-maybe.github.io/okkhor/)** Bangla typing in the browser. Type roman letters, pick from ranked Bangla suggestions, and keep drafts in your browser. Installable and works offline.
- **[React TV Remote](https://github.com/ashik-maybe/tv-remote-web)** Controls my Android TV over the local network using Google's own remote protocol. No TV app and no cloud.
- **[Frog Contribution Graph](https://github.com/ashik-maybe/frog-contribution-graph)** A GitHub Action that draws your contribution graph as a Bangladeshi pond, with a frog hopping your commits. On the Marketplace.
- **[Ana Gonda Calculator](https://github.com/ashik-maybe/anagonda-calculator-app)** Land-share calculator for Bangladeshi deeds. Exact fractions instead of rounded decimals, backed by 174 tests. Runs fully offline.
- **[BDIX Live Server Tests](https://github.com/ashik-maybe/bdix-ftp-server-tester)** Async Python CLI that checks 886 BDIX FTP and media servers, because the community list is mostly stale.
